## v1.0.0
Features:
- Server triggers:
	- Wait for new console message
	- Wait for power status change
	- Stats update (network, RAM, disk usage)
- User:
  - Get own profile
  - Send a command to server console
  - Control power state of the server
  - Wait for one of certain power states of the server
- Administration:
	- Get users list
	- Get servers list
- Credentials
    - API Key
    - Cookies
